# addon-synology (archived)

This repository is retired and read-only. OpenAbstractions 0.9.0 has one way to use a NAS: the **download archive**. In Settings, you choose a shared folder on any NAS, USB disk or other PC. OpenAbstractions copies each verified download there and reads models back from it. Nothing is installed on the NAS.

See https://github.com/openabstractions for the current projects.

The previous README is preserved in this repository's history.
